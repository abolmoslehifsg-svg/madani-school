# سامانه مدیریت مدرسه سمپاد شهید مدنی

یک پروژه‌ی کامل و آماده‌ی آپلود: **بک‌اند Flask + SQLite** و **فرانت‌اند ماژولار**.
همه‌چیز (فونت، کتابخانه‌ی اکسل، دیتابیس) داخل خود پروژه است؛ به CDN، Redis، Node یا سرویس دیگری نیاز ندارید.

## راه‌اندازی سریع

```bash
pip install -r requirements.txt
python app.py            # http://localhost:8000
```

اولین بار که صفحه را باز کنید، فرم **«راه‌اندازی اولیه»** نمایش داده می‌شود؛ حساب مدیر را همان‌جا بسازید.
(رمز پیش‌فرض وجود ندارد.) دیتابیس به‌صورت خودکار در `instance/madani.db` ساخته می‌شود.

## استقرار روی سرور

### VPS (اوبونتو/دبیان) با gunicorn + nginx
1. پوشه را در `/opt/madani-school` بگذارید و `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt` بزنید.
2. فایل `deploy/madani-school.service` را در systemd نصب و فعال کنید (`systemctl enable --now madani-school`).
3. `deploy/nginx.conf` را نصب و با certbot گواهی HTTPS بگیرید.
4. **پیش از اولین اجرا روی اینترنت** مقدار `MADANI_SETUP_TOKEN` را تنظیم کنید تا فقط شما بتوانید اولین مدیر را بسازید.

### هاست اشتراکی cPanel (Passenger / «Setup Python App»)
پروژه را آپلود کنید، فایل راه‌انداز را `passenger_wsgi.py` و اسم برنامه را `application` بگذارید، سپس `pip install -r requirements.txt`.

### Docker
```bash
docker build -t madani-school .
docker run -d -p 8000:8000 -v madani-data:/data -e MADANI_SETUP_TOKEN=xxxx madani-school
```

## تنظیمات (همه اختیاری — `.env.example`)
| متغیر | کار |
|---|---|
| `MADANI_SETUP_TOKEN` | توکن لازم برای ساخت اولین مدیر |
| `MADANI_DB_PATH` | مسیر فایل دیتابیس |
| `MADANI_BEHIND_PROXY=1` | وقتی پشت nginx/Cloudflare هستید |
| `MADANI_COOKIE_SECURE` | `auto` (پیش‌فرض) / `true` / `false` |
| `MADANI_MAX_REQUEST_MB` | حداکثر حجم درخواست (عکس‌ها) |

```
app.py  wsgi.py  passenger_wsgi.py
```

## امنیت (آنچه واقعاً روی سرور اعمال می‌شود)
- رمزها با PBKDF2‑SHA256 (۲۰۰ هزار تکرار) هش می‌شوند؛ هرگز به مرورگر برنمی‌گردند.
- نشست: توکن تصادفی در کوکی HttpOnly + SameSite=Lax؛ در دیتابیس فقط هش آن ذخیره می‌شود. محافظ CSRF با هدر سفارشی.
- قفل ۵ دقیقه‌ای پس از ۵ ورود ناموفق (به‌ازای نام کاربری و IP).
- **هر نقش فقط داده‌ی مجاز خودش را دریافت می‌کند** (مثلاً دانش‌آموز فقط نمره‌ی خودش) و **هر نوشتن در سرور بررسی دسترسی می‌شود**؛ معلم فقط کلاس‌های خودش، دانش‌آموز/ولی فقط رأی/ارسال تکلیف/مرخصیِ خودشان. هرچه رد شود، مرورگر دوباره از سرور همگام می‌شود.
- آزمون‌ها سمت سرور تصحیح می‌شوند و پاسخ صحیح به مرورگر دانش‌آموز نمی‌رسد.
- تأیید دو مرحله‌ای واقعی (TOTP، سازگار با Google Authenticator) از «حساب من».
- کد ملی، نمره، مبلغ و ... سمت سرور هم اعتبارسنجی می‌شوند؛ گزارش عملیات را سرور مهر می‌زند (قابل جعل نیست).

## پشتیبان‌گیری
تنظیمات ← «دانلود پشتیبان کامل» (فقط مدیر). فایل `.db` است؛ برای بازیابی، سرویس را متوقف و فایل را جایگزین `instance/madani.db` کنید.

## تغییرات نسبت به فایل تک‌تکه‌ی قبلی
- نام: «مدرسه پرتو» ← «مدرسه سمپاد شهید مدنی» (عنوان، لوگو، داده‌ی نمونه، کارنامه، کلیدهای ذخیره‌سازی).
- فایل ۴۲۰۰ خطی به ۹۴ ماژول کوچک تقسیم شد (هر صفحه، هر گروه اکشن، هر سرویس یک فایل).
- بک‌اند کامل جدید؛ همگام‌سازی خودکار همه‌ی تغییرها (دیگر فقط بخشی از اکشن‌ها به سرور می‌رفت).
- ۲FA نمایشیِ «کد در toast» با TOTP واقعی جایگزین شد. WebSocket با polling سبک عوض شد (روی هر هاستی کار می‌کند).
- فونت و کتابخانه‌ی اکسل محلی شدند (بدون اینترنت هم کار می‌کند).
- رفع دو باگ قدیمی: `renderQuizSession` تعریف‌نشده (شروع آزمون خطا می‌داد) و `provEvents` تعریف‌نشده (افزودن کوپن توسط مسئول رویداد).
- دکمه‌ی «بازنشانی رمز» برای مدیر/معاون؛ بدون ایمیل/پیامک، رمز فراموش‌شده را مدیر بازنشانی می‌کند.
- اگر بک‌اند در دسترس نباشد (مثلاً GitHub Pages)، همان نسخه‌ی آفلاین/نمایشی قبلی کار می‌کند.

## محدودیت‌های شناخته‌شده
- CSP به‌خاطر `onclick/onsubmit` درون HTML ناچار `'unsafe-inline'` دارد؛ حذف کامل آن نیازمند بازنویسی همه‌ی قالب‌هاست.
- رأی‌گیری شورا و نظرسنجی برای نقش‌های کارمندی (معلم/معاون/مدیر) محرمانه نیست (نگاشت رأی‌ها قابل مشاهده است).
- Polling هر ۵ ثانیه است؛ برای چند هزار کاربر هم‌زمان باید gunicorn را با worker بیشتر یا پشت nginx اجرا کنید.
- لایه‌ی فرانت‌اند (قالب‌های HTML درون JS) تقسیم و وصله شد، اما بازنویسیِ کامل به سبک «کلین‌کد» برای هر تابع انجام نشده است.
