# سامانه مدیریت مدرسه سمپاد شهید مدنی

نسخه دمو / آفلاین برای **GitHub Pages** (فقط فرانت‌اند).

## وضعیت فعلی
- `index.html` و بخشی از CSS اضافه شده.
- برای کامل شدن، پوشه `js/` از فایل زیپ را از طریق GitHub (Upload files) آپلود کنید.

## اجرای کامل روی سرور
پروژه اصلی (Flask + SQLite) برای سرور واقعی است:
```bash
pip install -r requirements.txt
python app.py
```
